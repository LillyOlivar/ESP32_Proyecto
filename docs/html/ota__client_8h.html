◆ ota_client_run()

esp_err_t ota_client_run ( const ota_client_config_t * cfg)

Descarga, valida e instala un firmware (bloqueante).

Pasos: conexion TLS, lectura del descriptor de la imagen, comparacion de version, descarga a la particion inactiva, verificacion de la imagen y seleccion de la nueva particion de arranque. No reinicia el dispositivo.

Parámetros
[in]cfgConfiguracion (no NULL; url y cert_pem no NULL; timeout_ms > 0).
Devuelve
ESP_OK si la imagen quedo instalada y lista para arrancar; ESP_ERR_INVALID_ARG si la configuracion es invalida; ESP_ERR_INVALID_VERSION si la version es igual y se pidio omitirla; ESP_ERR_INVALID_SIZE si la descarga quedo incompleta; otro codigo esp_err_t si falla la conexion, la descarga o la validacion.
Atención
Consume varios KB de pila; llamar desde una tarea con >= 8192 bytes.

◆ ota_client_start_task()

esp_err_t ota_client_start_task ( const ota_client_config_t * cfg)

Crea una tarea que ejecuta ota_client_run() y reinicia si tiene exito.

Parámetros
[in]cfgConfiguracion; se copia internamente, pero los punteros url y cert_pem deben seguir validos mientras la tarea se ejecute.
Devuelve
ESP_OK si la tarea fue creada; ESP_ERR_INVALID_ARG o ESP_ERR_INVALID_STATE (ya en ejecucion); ESP_ERR_NO_MEM si no se pudo crear la tarea.
Nota
Si falla la actualizacion, el dispositivo sigue con el firmware actual.
