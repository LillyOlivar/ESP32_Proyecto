◆ wifi_sta_connect()

esp_err_t wifi_sta_connect ( const char * ssid,
const char * password,
int max_retry,
TickType_t timeout )

Conecta el ESP32 a una red Wi-Fi y espera a obtener direccion IP.

Parámetros
[in]ssidSSID de la red (no NULL ni vacio).
[in]passwordContrasena (NULL o "" para red abierta).
[in]max_retryReintentos maximos tras una desconexion.
[in]timeoutTiempo maximo de espera en ticks de FreeRTOS.
Devuelve
ESP_OK si se obtuvo IP; ESP_ERR_INVALID_ARG si el SSID es invalido; ESP_FAIL si se agotaron los reintentos; ESP_ERR_TIMEOUT si vencio el tiempo.
Nota
Requiere haber llamado antes a nvs_flash_init(), esp_netif_init() y esp_event_loop_create_default().
Atención
Debe llamarse una sola vez.
