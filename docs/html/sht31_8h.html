◆ sht31_init()

esp_err_t sht31_init ( int sda_gpio,
int scl_gpio,
uint8_t addr,
uint32_t freq_hz,
bool pullup )

Inicializa el bus I2C y registra el SHT31.

Parámetros
[in]sda_gpioGPIO de SDA (>= 0).
[in]scl_gpioGPIO de SCL (>= 0).
[in]addrDireccion I2C de 7 bits (0x44 o 0x45).
[in]freq_hzFrecuencia del bus en Hz (> 0).
[in]pulluptrue para activar los pull-ups internos.
Devuelve
ESP_OK; ESP_ERR_INVALID_ARG si los pines/parametros son invalidos; ESP_ERR_INVALID_STATE si ya estaba inicializado; otro error de driver.
Nota
Los pines dependen del cableado del usuario; no se asumen valores.

esp_err_t sht31_read ( float * temp_c,

Realiza una medicion unica (alta repeticion, sin clock stretching).

Parámetros
[out]temp_cTemperatura en C (no NULL).
[out]humidity_pctHumedad relativa en % (no NULL).
Devuelve
ESP_OK; ESP_ERR_INVALID_STATE si no esta inicializado; ESP_ERR_INVALID_ARG si un puntero es NULL; ESP_ERR_INVALID_CRC si falla el CRC; otro error de I2C.
Nota
Bloquea ~20 ms durante la conversion.
