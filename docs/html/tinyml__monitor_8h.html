◆ tinyml_monitor_process()

esp_err_t tinyml_monitor_process ( float temp_c,
float humidity_pct,
sensor_insights_t * out )

Procesa una lectura: punto de rocio, VPD y deteccion de anomalia.

Parámetros
[in]temp_cTemperatura en C (finita, entre -40 y 125, rango del SHT31).
[in]humidity_pctHumedad relativa en % (finita, 0 < RH <= 100).
[out]outResultado (no NULL).
Devuelve
ESP_OK; ESP_ERR_INVALID_ARG si out es NULL o las entradas estan fuera de rango (RH = 0 haria indefinido el logaritmo del punto de rocio).
Nota
Cuando is_anomaly es true, la aplicacion puede decidir marcar el evento o aumentar el muestreo; esa logica y la escritura en MicroSD NO estan implementadas en este modulo.
